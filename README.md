# NOKHBA AI STUDIO

## استوديو نخبة للذكاء الاصطناعي

مشروع مستقل لتطوير أدوات الذكاء الاصطناعي واختبارها بأمان.

### مساحات العمل
- المساعد النصي.
- استوديو الصور.
- استوديو الصوت والتفريغ.
- استوديو السينما.
- NOKHBA AI CORE: بوابة خلفية مركزية مبنية على Cloudflare Workers AI.

### مبادئ المشروع
- التطوير والاختبار في بيئة مستقلة.
- عدم الاتصال التلقائي بالإنتاج.
- حماية مفاتيح API والأسرار.
- عدم إعلان أي خدمة جاهزة قبل اختبارها فعلياً.
- جميع تغييرات المشاريع الأخرى تتم عبر فروع وطلبات مراجعة، لا عبر تعديل الإنتاج مباشرة.

### NOKHBA AI CORE — الإصدار التأسيسي
أضيفت بوابة Cloudflare Worker في `src/index.js` مع:
- `GET /health` لفحص الحياة دون كشف أسرار.
- `POST /v1/chat` لاستدلال موثق بمفتاح خادمي.
- ربط Workers AI باسم `AI`.
- التحقق من المدخلات وحدود طول المحادثة والمخرجات.
- اختبارات Node.js وGitHub Actions.

هذه نسخة تأسيسية وليست وكيل إصلاح ذاتي بعد. لا تملك صلاحية الوصول إلى GitHub أو تعديل المستودعات أو النشر. أي قدرات إصلاح مستقبلية ستضاف كوحدات منفصلة بصلاحيات محدودة وسجل تدقيق ومراجعة بشرية.
